移除同步与归档功能，管理页面简化为订阅、文件、分享和设置。

- 删除同步列表、同步编辑页及归档页，清理导航、标签筛选和编辑器中的相关入口。
- 移除 Gist 上传／下载、同步设置、同步任务与归档恢复接口。旧版客户端的 `mode=archive` 删除请求返回 `400`，防止误删。
- “我的”页保留本地 JSON 备份与恢复；普通资源下载使用的 GitHub 代理与匹配正则移到请求配置。
- 保留订阅启停与自动检测、预览、文件处理、原分享链接、管理认证及在线更新／回退。
- 现有同步和归档历史记录保持原样，不再执行；远端 Gist 不作改动。部署仍保留升级前数据快照。

服务器只下载并运行本次发布包，无需编译。详见 [部署手册](https://github.com/ywainzh/Sub-Store/blob/release/deploy/README.md)。
