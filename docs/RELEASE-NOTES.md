订阅启停与到期／流量自动管理。

- 单条与组合订阅卡片增加启停开关，显示手动停用、已到期、流量用尽及部分来源可用状态；编辑页可关闭远程订阅自动检测。
- 远程来源启动后检查，此后每 30 分钟检查，最多两条并发；到期或流量用尽自动停用，确认续费／流量重置后恢复。手动关闭优先，后台不会重新开启。
- 多 URL 逐条判断，混合订阅保留本地内容。停用 A 后，组合保留成员关系和原分享 token，继续输出 B、C；重新开启后原链接恢复。
- 下载、分享、原始节点、组合预览和文件节点注入执行统一过滤；全部来源停用返回 `409`，缓存、`noFlow` 查询参数和失败兜底不能绕过。
- 网络故障、信息缺失或非法额度不会触发新的流量用尽判定，也不会解除已确认的限制。立即检测跳过旧流量缓存；状态查询不访问供应商。
- 页面在可见时每分钟读取状态；支持手机、双列、简洁模式、深色模式和键盘操作。组合的流量显示与透传改取首个实际可用来源。
- 启停配置与最新检测状态在重启后保留，不新增历史备份；继续使用现有管理认证及网页更新／回退流程。

客户端已下载的节点不会立即改变，Clash／小火箭下次更新订阅时才同步。

新增配置使用可选字段，数据格式仍为 `2.0`。**旧版 `v0.1.1` 及更早版本不执行启停和自动管理规则**；回退后即使保留配置字段，停用来源也可能重新输出。常态仍只保留当前版、上一版和一份部署前快照，认证状态独立保存。
