单管理员认证与独立版本管理首版。

- 管理 API、数据导出和普通下载需要登录；浏览器会话保持 30 天，自动化使用独立 API token。
- “我的 → 关于 Sub-Store”可检查本项目更新、选择兼容历史版本回退，并恢复查询部署进度。
- 更新任务由独立 systemd 助手执行；健康检查失败自动恢复程序和数据。
- 常态仅保留当前版、上一版和一份部署前数据快照；认证状态独立保存。
- 固定工具链及依赖锁文件，构建指定 tag，测试和发布包启动检查通过后才发布。

首次安装或从 v0.0.1 迁移须通过 SSH 安装部署助手并初始化认证，详见 [部署手册](https://github.com/ywainzh/Sub-Store/blob/release/deploy/README.md)。v0.0.1 不支持网页回退。
